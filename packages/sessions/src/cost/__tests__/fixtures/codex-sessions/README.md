# Codex rollout fixtures (sessions-spike v5-3)

These `rollout-*.jsonl` files are **redacted copies of real Codex CLI
rollouts** from `~/.codex/sessions/2026/05/11/` on the build machine — the
only two rollouts present there. They are NOT hand-authored (design §4 forbids
hand-authored JSON fixtures).

`REDACTION.py` is the exact, re-runnable redaction script for the three
real-derived fixtures (`rollout-costed-multiturn`, `rollout-info-null-only`,
`rollout-abnormal-costed-unattributed`). `rollout-malformed-line.jsonl` is
NOT generated by the script — it is hand-derived from the redacted costed
fixture with one malformed JSON line + one blank line injected, since
testing malformed-line skipping requires deliberately corrupt input.
`REDACTION.py` keeps ONLY the three record types v5-3's reader parses
(`session_meta`, `turn_context`, `event_msg`/`token_count`) and, within
those, ONLY the allow-listed fields
(`cwd`, `model`, `info.total_token_usage`, `timestamp`). Every
prompt/response-bearing record (`response_item`, `agent_message`,
`user_message`, `task_*`) is dropped entirely; `git`, `base_instructions`,
ids, `rate_limits`, sandbox policy etc. are stripped. The real `cwd` is
rewritten to a synthetic placeholder so no real filesystem path is committed.

The "last turn_context / last non-null token_count wins" semantics need
multi-turn structure the single real runs lack, so `rollout-costed-multiturn`
composes real redacted records (an extra `turn_context` and `token_count` are
copies of real records with varied model id / token figures). Every record is
still a structurally-real Codex record — no field shape is invented.

These fixtures live under `cost/__tests__/fixtures/` (NOT
`src/__tests__/fixtures/`) because the v4 `fixture-marker.setup.ts` privacy
guard scans only the latter; a `.jsonl` here is not a synthetic Claude
transcript and would (wrongly) fail that guard's marker assertion.

| file | shape |
|------|-------|
| `2026/05/11/rollout-costed-multiturn.jsonl` | full costed run; 2 turn_context (last = gpt-5.5), 2 non-null token_count (last wins), 1 info:null; attributed cwd |
| `2026/05/11/rollout-info-null-only.jsonl` | a token_count record exists but ZERO non-null-info ones → `costUsd: null` |
| `2026/05/11/rollout-malformed-line.jsonl` | costed run with one malformed JSON line + one blank line injected |
| `2026/05/12/rollout-abnormal-costed-unattributed.jsonl` | ends after a non-null token_count with no terminator; cwd under no project |
